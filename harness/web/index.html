            Copy as new draft
            
    
            
    
            Copies the original request, source snapshot, workflow, filename and expected text into a separate local task. It does not use the generated proposal as the new source.
            
    
            Model routes, approvals, attempts, results, checks, usage and terminal control are not copied. Nothing runs until you select a route and approve the new draft.
            
    
            
    
            Pending request identifiers are kept in this tab to recover a lost response after reload. They contain no request or source text.
            
    
            
              
  
    
            
      
            Edit proposal
            
      
            The original proposal stays in this local task. Saving updates the review candidate and reruns basic checks. It does not modify a file on your computer.
            
      
      
            The 12,000-character limit includes restored line endings.

            Review task removal
            
    
            
    
            Read what will be removed and what will remain. This does not securely erase files or remove provider copies.

            Lock the workspace?
            
    
            Every open view of this workspace locks, not only this one. Each needs the access file to unlock.
            
    
            Approved work keeps running while locked. Lock is not Stop: use Stop on a running task to end it.
            
    
            Terminal control is released. After unlocking, views reopen read-only and you take control again yourself.
            
    
            Locking does not erase what was already shown, copied or downloaded.
